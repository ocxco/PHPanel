# 系统设置

偏好设置包含“外观”“系统设置”“网络与下载”“本地存储”四个标签。

## 开机自动启动

默认关闭。开启后，在当前用户登录 Windows 时自动打开 PHPanel；它不要求管理员权限，也不会更改 Nginx、Redis、MySQL 的 Windows 系统服务启动方式。

注册位置为当前用户 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 中的 `PHPanel` 值。启动命令包含当前 EXE 的绝对路径及实际数据目录，支持有空格的路径和 `PHPANEL_DATA_DIR` 指定的目录。开启时更新为当前程序位置；关闭时只移除与当前程序及数据目录匹配的启动项。

便携目录移动后，需要在新位置重新保存开机启动设置。Windows 任务管理器或安全软件也可能禁用登录启动项。

## 静默启动

默认关闭。开启后，下次正常启动时直接隐藏到系统托盘，不显示任务栏窗口。点击托盘图标可打开面板。管理员授权重启会显示窗口，便于继续刚才的操作。初始化或托盘创建失败时会显示窗口，避免程序无法找回。已有的 `startMinimized` 设置会沿用为静默启动开关。

## 关闭按钮行为

- **首次关闭时询问**：首次点击窗口关闭按钮时弹出选择，提供“退出程序”和“最小化到托盘”。选择会自动保存，之后按选定行为执行；取消或保存失败时保留窗口，下次关闭仍询问。旧版本设置没有确认标记，也会在首次关闭时询问。可在系统设置中重新选择此项，或直接指定以下两种行为。
- **退出程序**：关闭面板并停止它管理的普通实例；Windows 系统服务和受其保护的 PHP 按原有规则继续运行。
- **最小化到托盘**：点击窗口关闭按钮时隐藏窗口，面板、下载和实例继续运行。点击托盘图标可重新打开，右键菜单提供“打开 PHPanel”和“退出 PHPanel”。

托盘菜单“退出 PHPanel”始终退出程序，不会被首次关闭选择或最小化到托盘的设置拦截。管理员授权重启同样会正常退出旧进程。托盘不可用时，首次关闭弹窗禁用“最小化到托盘”；已确认托盘行为的关闭按钮按直接退出处理，避免窗口隐藏后无法找回。

同一数据目录的第二次程序启动会尝试恢复已有窗口。不同数据目录可以分别运行。托盘图标可能位于 Windows 的隐藏图标区域；资源管理器重启后会尝试恢复图标。

## 保存与验证

系统设置独立保存到 `state/panel.json`，修改网络或主题设置不会覆盖它。开机启动写入与设置保存失败时，会恢复先前的启动项。系统设置和网络与下载的保存按钮统一放在设置面板右下方；外观修改立即保存，本地存储没有保存按钮。

单元测试覆盖首次关闭选择与取消、保存失败、关闭与托盘行为决策、明确退出、隐藏启动及失败回退、启动命令转义、设置保存和注册失败回滚。界面验证使用浏览器预览。开发验证不修改真实开机启动项，也不停止用户实例；原生托盘交互需在实际运行的新版中验证。
