# Windows 安装目录发布重试

解压和可执行文件校验完成后，PHPanel 将 `.install-*` 临时目录改名为正式版本目录。Windows 返回 Access denied、Sharing violation 或 Lock violation 时，可能是临时文件句柄或文件系统过滤器仍占用新解压文件。此错误本身不能确定具体占用进程，也不能排除权限问题。

安装发布现在按 50 ms 起步、最多 500 ms 间隔重试，最长等待 10 秒。等待期间保留完整的临时目录。其它错误立即返回；目标目录已存在时拒绝覆盖。只有成功改名后才登记为已安装。

下载任务退出取消时停止等待。下载缓存保留，在下载中心重试会先核对已缓存 ZIP 的摘要，符合预期时直接重新安装。

验证包括三类 Windows 错误的恢复、持续错误超时、取消等待、不覆盖已有目录，以及用实际 Windows 文件句柄锁定文件再释放后发布成功。PHP 8.3.36-1 在隔离目录连续安装执行三次，并通过 Nginx/PHP 8.3、8.4 的真实 HTTP 请求验证。
