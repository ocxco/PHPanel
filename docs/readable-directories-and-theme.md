# 可读目录与界面布局

程序包目录使用 `packages/package-<组件><完整版本>`，实例目录使用 `instances/instance-<组件><完整版本>`。例如 `package-php8.5.12-1` 和 `instance-nginx1.31.8`。同名版本或多实例追加 `-2`、`-3` 序号，保留目录中的文件。内部 ID 保持稳定，网站和服务的关联不变。

升级时在数据目录独占锁内迁移现有文件夹，更新可执行文件路径及配置中的程序包、日志、数据、临时目录路径。迁移记录保存在 `state/directory-migration.json`，发生错误会恢复原目录；进程中断后启动时恢复未完成的迁移。旧元数据保存在 `state/panel.json.before-directory-rename`。下载缓存仍使用 SHA-256 文件名，便于校验和重复使用。

服务实例按 PHP、Nginx、MySQL、Redis 分组，通常每行两个卡片，窄窗口调整为单列。卡片展示名称、状态、地址、PID 和操作，不展示目录路径。配置编辑、目录、日志、启停和删除入口保留。

环境管理的四个组件卡片缩为紧凑横向摘要。偏好设置分为外观、网络与下载、本地存储三个 Tab。网络表单在切换 Tab 时保留编辑草稿。

外观提供日间、夜间、跟随系统三种主题，选择后立即生效，保存在面板设置中；跟随系统监听 Windows 外观变化。页面、弹窗、日志与 CodeMirror 使用同一套主题色，主题切换不改变网络偏好。
