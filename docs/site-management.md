# 网站与配置管理

网站支持创建、编辑和删除。编辑可设置名称、网站端口、项目目录、模板、Nginx 校验版本和 PHP 实例。删除只移除管理记录和站点配置，项目文件保留。

服务实例的 PHP、Redis、MySQL 端口可在停止后修改，保存后由用户手动启动。PHP 修改端口会保留站点配置中的其它内容，仅替换引用它的 FastCGI 地址，检查后应用到 Nginx。与实例、网站或外部监听冲突的端口会被拒绝；配置检查失败则保留原端口及原文件。

PHP / MySQL / Redis 每个已安装版本只允许一个实例处于启动、运行或停止过程，不同版本可同时运行。Nginx 所有版本合计只允许一个实例运行或启动，切换版本需先停止当前实例。Nginx 实例不设置端口，站点独立设置端口，不同域名可共享端口。

启动 Nginx 默认联动启动所有共享网站配置引用的 PHP，并复用已运行的实例。联动选项位于 Nginx 卡片的“启动设置”；默认停止 Nginx 时保留 PHP，也可以选择“一起停止”本次自动启动的 PHP。启动后的新增网站或 PHP 版本变更仍需手动启动新引用的 PHP，或停止并重新启动 Nginx 触发联动。

| 模板 | 规则 |
|---|---|
| 通用 PHP | index.php 前端控制器 |
| Laravel | index.php 路由回退；网站目录选择项目 public |
| ThinkPHP | index.php?s=$uri 路由回退；网站目录选择项目 public |
| WordPress | index.php 路由回退和 favicon/robots 规则 |
| 静态站点 | index.html；找不到返回 404；无需 PHP，并阻止 PHP 源码输出 |

模板提供服务器配置，不安装框架或 WordPress。留空目录会建立本地欢迎页面。当前使用 <名称>.localhost，完整自定义域名和 SSL 尚未提供。

主配置位于 instances/<实例 ID>/config/nginx.conf，使用 4 个空格缩进，通过绝对 include 加载 EXE 旁 sites/*.conf。站点文件为 <数据根目录>/sites/<站点 ID>.conf，所有 Nginx 版本共享。旧实例内部站点配置和备份在升级时复制到共享目录，保留手工修改。主配置只替换站点 include，保留全局自定义项和 .before-sites-migration 备份。删除任意或全部 Nginx 实例都保留站点记录和共享配置，重新创建后可以直接加载。Redis 配置使用平面指令格式，默认内容按网络、日志、持久化分组。

“服务实例 → 编辑配置”可编辑 php.ini、my.ini、redis.conf、nginx.conf 及各站点配置；“网站管理 → 配置”直接打开对应文件。编辑器使用 CodeMirror 6，支持行号、语法高亮、搜索和撤销。只有打开编辑窗口才加载编辑器资源。

站点表单中的 Nginx 选择只用于无运行实例时的语法校验，实际运行版本在服务实例中切换。Nginx 保存前在候选目录检查整套共享配置，成功后发布并对当前运行的实例发送 reload；校验、发布或重载失败时恢复旧文件。主配置必须保留站点 include。其它组件保存后需要重启实例应用。编辑器检测文件内容版本，防止用旧内容覆盖外部修改。

直接编辑的内容会在重启服务和修改其它网站时保留。编辑网站表单会按模板重新生成该站点配置，原文件保存在 .before-site-change；普通配置编辑保留 .before-edit，路径修正保留 .before-path-fix。删除网站仍保留项目文件和配置备份。Nginx 重载日志在 logs/site-reload.log。

验证覆盖版本并发启动限制、旧端口迁移、端口冲突、所有模板、独立文件、直接编辑保留、过期编辑拒绝和失败回滚。真实 Windows Nginx/PHP 测试覆盖 HTTP 请求、框架路径回退、静态站点防止 PHP 源码输出、编辑器保存校验和热重载、服务重启保留配置。
