# 自动更新组件版本目录

PHPanel 运行时读取上游目录，普通版本发布不再需要修改内置版本数组或重新编译程序。内置目录继续作为首次启动及断网时的基础数据，成功发现的版本持久化到本地元数据。

## 默认行为

- 默认开启自动更新，每 6 小时检查一次。
- 启动后后台检查目录是否过期，不阻塞界面；未到检查间隔时直接使用缓存。
- “环境管理 → 刷新目录”可立即检查。
- “偏好设置 → 版本目录自动更新”可关闭自动检查或设置 1–168 小时间隔。
- 更新时只传输目录和元数据，不预下载所有安装包。
- 界面显示更新状态、最近成功时间和部分失败信息。
- 某个来源失败时，其它来源仍可更新，已有版本、实例和自定义镜像保留。
- 每页显示 30 个版本，搜索覆盖整个目录，避免自动发现较多版本后创建过多界面节点。

自动更新的是可用安装包目录。选择下载、安装或创建实例仍由用户执行；程序不会因此更换已运行的 PHP/MySQL/Redis 版本。

## 各组件来源

| 组件 | 版本发现 | 安装前验证 |
| --- | --- | --- |
| PHP | PHP Windows 官方 releases.json，自动识别 NTS x64 构建 | 官方 SHA-256 |
| Redis | redis-windows 社区 GitHub Releases，读取非预发布 x64 Cygwin ZIP | GitHub Release SHA-256 |
| Nginx | 官方下载 HTML 中的 Windows ZIP 链接 | 已知 SHA-256，或官方 OpenPGP 签名 |
| MySQL | 官方 Windows 下载页面及其动态分支选项 | 已知 SHA-256，或官方 OpenPGP 签名 |

MySQL 页面暂不可达时，备用发现源读取 Scoop 的 mysql/mysql-lts **版本号**，再检查官方 ZIP 地址。不会将 MSI 的摘要用于 ZIP。页面/来源的部分失败显示在更新详情中。

新发现的 Nginx/MySQL 版本可能尚无预先记录的 SHA-256，界面会显示“官方签名 / 安装时核验”，而非伪装为已通过 SHA-256 校验。下载安装时验证官方 .asc 签名，公钥从经过 HTTPS 认证的官方公钥目录取得；验证成功后保存文件 SHA-256。签名不符时拒绝安装。公钥保存为本地公开证书缓存，程序不需要外部 gpg 可执行文件。

一个版本的制品身份、下载任务和已安装程序引用在签名验证后保持一致。用户的镜像下载也必须通过相同签名或预期摘要验证。

## 额外目录源

在偏好设置填写一个或多个受信任的 HTTPS JSON 地址，例如部署在国内静态文件服务器、对象存储或组织内部服务器。只需更新这个数据文件，客户端下一次检查就会同步新版本，不需要修改客户端代码。

```json
{
  "schemaVersion": 1,
  "artifacts": [
    {
      "component": "mysql",
      "version": "8.4.8",
      "build": "Windows x64 / 8.4 LTS",
      "publisher": "MySQL Community 官方",
      "sha256": "53685bb61a1efc5ecc1b35c1b6bd0d30ba799f4943a1ef2c34df464f5a774c7f",
      "sources": [
        {
          "name": "MySQL 官方归档",
          "url": "https://cdn.mysql.com/archives/mysql-8.4/mysql-8.4.8-winx64.zip"
        }
      ]
    }
  ]
}
```

每份目录最多 5000 个条目、4 MiB；最多配置 8 个额外源。每个条目必须提供 SHA-256，或受支持的官方签名元数据。目录中的脚本/安装命令不会执行。已固定的不同摘要不会被同名更新静默替换。

受支持的签名元数据为 `signatureAuthority`（mysql/nginx）和 `signatureUrl`。地址必须是该版本对应的官方 HTTPS ZIP .asc 地址，不能指定任意第三方公钥来绕过验证。

本机 HTTP 地址只用于开发测试；远程目录要求 HTTPS。目录托管服务尚未替用户部署，默认四个上游发现源已经能够独立工作。

## 验证与维护

正式目录测试位于 tests/panel，使用 tests/run.ps1 -Integration 筛选运行。测试需要的安装包由维护者在独立测试目录准备；仓库不保留历史下载或探测产物。

普通版本发布由目录处理，上游页面结构、发行格式或安装协议变化可能需要更新适配器。
