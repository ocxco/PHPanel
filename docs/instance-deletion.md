# 删除服务实例

服务实例列表提供垃圾桶按钮。运行、启动或停止中的实例需先完成停止操作。点击后显示实例名称、组件版本、端口和完整目录，确认后永久删除该目录中的配置、日志和数据。

已注册为 Windows 系统服务的实例需要先停止、注销服务，才能删除。注销仅移除 Windows 服务注册，保留实例配置和数据。后端会查询真实系统服务状态，防止删除仍由 Windows 管理的实例。

Nginx 仍有正在运行的联动 PHP 时，应先通过“一起停止”或 PHP 卡片的停止按钮结束这些实例，再删除 Nginx，避免后台 PHP 的归属记录失效。

MySQL 数据库文件和 Redis 持久化数据也在删除范围内，确认框会明确提示先备份。已安装的程序版本保留，因此可以重新创建实例。环境管理中只有该版本仍有其它实例时才显示“查看实例”；删除最后一个实例后显示“创建实例”。

PHP 实例仍被网站使用时会阻止删除，确认框列出相关网站。Nginx 可以在停止后删除，独立 sites 目录中的配置和站点记录会保留，并清除已删除的校验实例选择；新建 Nginx 可直接加载所有站点。项目目录不在实例删除范围内。

后端在网站操作锁和实例操作锁下检查运行状态及引用，只允许处理当前数据根目录中属于该实例的直接子目录。越界、指向其它实例或重定向目录均拒绝删除。

文件先移入同级临时清理目录，再保存管理记录，最后清理文件。管理记录保存失败时恢复原目录；若最后的文件清理失败，会明确说明实例记录已删除并给出残留目录。不存在的实例目录可以清理管理记录。

隔离目录测试覆盖数据删除、程序包保留、端口释放、运行/变更/引用拦截、路径保护、文件占用、保存失败回滚和缺失目录。真实 PHP 集成测试验证运行时拒绝删除，停止后删除并能使用保留的程序包重新创建和运行。
